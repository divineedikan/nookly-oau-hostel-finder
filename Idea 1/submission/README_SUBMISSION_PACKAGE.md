# Nookly Defence Submission Package

This folder contains the editable documentation package for defence.

## Required Final Flash Drive Arrangement

Create this final flash-drive folder:

```text
GROUP_XX_NOOKLY_OAU_HOSTEL_FINDER/
├── source-code/
├── presentation/
│   ├── Nookly_Presentation.pptx
│   └── Nookly_Presentation.pdf
├── report/
│   ├── Nookly_Project_Report.docx
│   └── Nookly_Project_Report.pdf
├── defence-notes/
│   └── Defence_QA.md
└── deployment-link.txt
```

## What To Copy Into `source-code/`

Copy the project code files from the project root:

```text
index.html
app.js
styles.css
theme.css
favicon.svg
requirements.txt
README.md
data/
docs/
scripts/
tests/
```

Do not copy temporary cache folders such as:

```text
__pycache__/
pytest-cache-files-*/
.pytest_cache/
```

## Export Instructions

### Report

1. Open `submission/report/Nookly_Project_Report.md`.
2. Copy the content into Microsoft Word or Google Docs.
3. Format title page, page numbers and spacing as required by your department.
4. Save as:
   - `Nookly_Project_Report.docx`
   - `Nookly_Project_Report.pdf`
5. Print five bound hard copies.

### Presentation

1. Open `submission/presentation/Nookly_Presentation_Slides.md`.
2. Create slides in PowerPoint using each section as one slide.
3. Save as:
   - `Nookly_Presentation.pptx`
   - `Nookly_Presentation.pdf`
